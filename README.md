## ⚡ Key Features

### 1. Interactive 3D Cyber Core
- Three.js-powered 3D security visualization.
- Interactive orbital rings and satellite data nodes.
- Mouse-responsive parallax and rotation.
- Interactive security scan pulse effects.
- Fallback rendering for restricted browser environments.

### 2. Animated Network Background
- HTML5 Canvas particle animation.
- Dynamic network nodes and connecting lines.
- Floating binary and cybersecurity protocol elements.
- Mouse-responsive particle interactions.

### 3. Cyber Sound Effects
- Web Audio API-based sound generation.
- Futuristic interface clicks and alert sounds.
- Access-granted and scan effects.
- Sound controls with audio muted by default.

### 4. Interactive Cyber CLI Terminal

A portfolio terminal with the following commands:

| Command | Description |
|---|---|
| `whoami` | Displays personal information |
| `skills` | Displays technical skills |
| `projects` | Shows featured projects |
| `labs` | Shows cybersecurity lab activities |
| `cloud` | Displays cloud computing experience |
| `education` | Displays academic information |
| `internship` | Displays internship experience |
| `cv` | Downloads the resume |
| `scan` | Runs a simulated security scan |
| `clear` | Clears terminal output |
| `exit` | Closes the terminal |

### 5. Responsive Portfolio
- Modern dark cybersecurity-inspired design.
- Electric blue and neon-inspired visual elements.
- Responsive desktop, tablet and mobile layouts.
- Interactive navigation.
- Certificate preview gallery.
- Resume download functionality.

## 💻 Run Locally

### Requirements

- Node.js
- npm
- Git

### Clone Repository

```bash
git clone https://github.com/vprijwal-bit/rijwal-vp-portfolio.git
```

### Open Project

```bash
cd rijwal-vp-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build Production Version

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🌍 Deployment

### Vercel — Current Hosting Platform

This portfolio is deployed on Vercel and connected to GitHub.

https://rijwal-vp-portfolio.vercel.app/

**Deployment Configuration**

| Setting | Value |
|---|---|
| Hosting | Vercel |
| Framework | Vite |
| Root Directory | `./` |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |
| Git Branch | `main` |

New changes pushed to the connected GitHub branch can automatically trigger a Vercel deployment.
